subtopic: Plain, twill and satin weaves

Woven fabrics are built from three basic weaves. In a plain weave, each crosswise yarn passes over one lengthwise yarn and under the next, like a checkerboard. It is the simplest weave, and the cloth is usually strong and durable with a smooth surface, as in cotton muslin. A twill weave shifts the crossing point one step on each row, which makes parallel diagonal ribs. Twill is sturdy, so it is used for work clothes, and denim, or maong, is a twill. A satin weave lets yarns float over four or more crossing yarns before going under. These long floats reflect light, so the face is glossy and smooth while the back is dull. The floats also snag easily, so satin is less durable than plain weave or twill.
Memory aid: "Plain = Plus, Twill = Tilt, Satin = Slide."
