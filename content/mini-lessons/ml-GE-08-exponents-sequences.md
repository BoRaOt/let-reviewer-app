**Exponent rules** for the same base:
- **Product rule:** aⁿ × aᵐ = aⁿ⁺ᵐ. Example: 2³ × 2⁴ = 2⁷ = 128.
- **Quotient rule:** aⁿ ÷ aᵐ = aⁿ⁻ᵐ. Example: 5⁶ ÷ 5⁴ = 5² = 25.
- **Power rule:** (aⁿ)ᵐ = aⁿᵐ.
- **Zero exponent:** any non-zero number to the zeroth power is **1**.
- **Negative exponent:** a⁻ⁿ = 1 ÷ aⁿ, so 2⁻³ = 1/8.

**Arithmetic sequences** add the same **common difference** d each time. The i-th term is aᵢ = a₁ + d(i − 1). For 4, 7, 10, 13 …, d = 3, so the 20th term is 4 + 3 × 19 = 61.

**Geometric sequences** multiply by the same **common ratio** r. In 3, 6, 12, 24 …, r = 2, so the next terms are 48 and 96. Savings that grow by a fixed percent each year form a geometric sequence.
Memory aid: "Multiply powers, add exponents; arithmetic adds, geometric multiplies."
