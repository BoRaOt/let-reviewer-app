Learn these pairings exactly.
- **Vitamin A:** night blindness is the most definitive sign. Severe deficiency causes xerophthalmia, dry eyes with Bitot's spots, which can end in blindness.
- **Vitamin D:** rickets in children, with soft, weak and deformed bones. In adults it is called osteomalacia.
- **Vitamin C:** scurvy, with bleeding gums, skin problems, painful joints and weakness. Vitamin C is needed to make collagen, which holds tissues together.
- **Thiamin, vitamin B1:** beriberi, which brings fatigue, confusion, leg pain, swelling and heart failure. It is common where white rice is the staple, because milling removes the vitamin-rich bran.
- **Niacin, vitamin B3:** pellagra, which begins with fatigue and indigestion and then shows the four D's: diarrhea, dermatitis, dementia and sometimes death.

Exam distractors usually swap these partners, such as scurvy with vitamin D, so check each pair carefully.
Memory aid: "A-eyes, D-bones, C-gums, B1-rice, B3-four D's."
