A **scoring rubric** describes what performance looks like at each level, so different raters, or the same rater on different days, score more consistently. This improves reliability, which is the weak point of performance tasks.

A **holistic rubric** gives one overall score from general descriptions, such as not proficient, partially proficient, proficient and advanced. It is quicker to build and to use, and suits a final overall judgment.

An **analytic rubric** describes levels for each criterion separately. For a sewing project the criteria might be measurement accuracy, seam quality, finishing, pressing and workplace safety, each scored on its own. It takes longer to build, but it shows learners exactly what to improve, so it is better for formative feedback.

Whichever type you choose, share the rubric with learners before the task.
Memory aid: "Holistic = one big score; Analytic = one score per part."
