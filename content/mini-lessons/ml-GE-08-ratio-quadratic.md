A **proportion** says two ratios are equal: a/b = c/d. Solve it by **cross-multiplying**: a × d = b × c. Example: a recipe uses 3 cups of rice for 4 servings. How much for 10 servings? 3/4 = x/10, so 4x = 30 and x = 7.5 cups. Proportions also handle map scales, unit prices and currency conversion.

A **linear equation** is solved by doing the same operation to both sides until the variable stands alone: 2x + 5 = 15 → 2x = 10 → x = 5.

A **quadratic equation** has an x² term. Write it in **standard form ax² + bx + c = 0**, then use the **quadratic formula**: x = [−b ± √(b² − 4ac)] ÷ 2a. Example: x² − 5x + 6 = 0 has a = 1, b = −5, c = 6, so x = [5 ± √(25 − 24)] ÷ 2 = 3 or 2. Check by substitution.
Memory aid: "Proportion: cross and solve; quadratic: standard form, then the formula."
