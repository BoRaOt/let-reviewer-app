# LET Study App

A free, offline study app for the Philippine **Licensure Examination for Teachers (LET), Secondary level**, TLE major with the **Home Economics** specialization. It runs in the browser, installs to a phone's home screen, and works without internet after the first visit.

**This is a study aid, not a PRC product.** Check PRC announcements for official exam details.

## What it does

- **Five tabs:** Today, Learn, Practice, Review, Progress.
- **Questions first.** Sessions start with retrieval. You choose an answer and rate your confidence (sure / unsure / guess) before you see the result.
- **Every option explained.** You see why the right answer is right and why each wrong option is wrong. A sure-but-wrong answer gets a short correction line.
- **A mini-lesson after each missed question** (100–150 words with a memory aid).
- **Spaced review.** Missed items, and correct items you were unsure of, return after 1, 3, 7 and 14 days. Two misses on the same subtopic in a week bring up the full lesson and add three extra items over the next three days.
- **Practice modes:** quick quiz, topic drill, interleaved mix (weighted to easily confused topics), rapid fire, smart review, timed part exams at exam pace (GenEd 48 s, ProfEd 72 s, Specialization 84 s per item, items drawn by the official TOS weights), and a full 450-item mock.
- **Daily plan** that fits 1–2 hours a day with rest days, in four phases up to an **editable exam date**. The default is a late-March-2027 placeholder until PRC posts the schedule. If you fall behind you choose to catch up in order or re-plan; nothing is deleted.
- **Readiness meter** per part (GenEd, ProfEd, Specialization), with the reported passing rule (general average ≥ 75%, no part below 50%) shown as reported, not verified.
- Lessons for all 36 TOS lines, cheat sheets (printable), glossary, common mistakes, memory aids, flashcards, bookmarks, search.
- Profiles, export/import backup, text size, dark mode. All data stays on the device.

All text is original, written from facts in Philippine laws and government issuances, open textbooks (OpenStax, University of Hawai'i, Seifert & Sutton) and other open sources. Every question, flashcard and lesson fact cites its source. See [`content/ATTRIBUTION.md`](content/ATTRIBUTION.md) and the in-app *Learn → Sources and licences* page.

Only items that passed a clearance check are published here: verified items only, every cited source with a licence that allows this use, and nothing of unclear origin.

## Layout

```
site/        the app (plain HTML, CSS, JavaScript; no build step, no external libraries)
  data/      compact data bundle the app loads
  sw.js      service worker (generated by scripts/build_sw.py)
content/     the same content in readable form: questions.json, flashcards.json,
             lessons/<part>/<line>.md, mini-lessons/<id>.md, sources.csv, ATTRIBUTION.md
scripts/     build_sw.py, check_site.py
tests/       logic.js, flows.js, smoke.js (Playwright)
```

## Run locally

```bash
python3 -m http.server -d site 8765
```

Then open http://localhost:8765/. The browser tests (need Playwright) cover the scheduler and plan logic, the main flows and a smoke run including offline reload; `.github/workflows/test.yml` runs them on every push:

```bash
node tests/logic.js && node tests/flows.js && node tests/smoke.js
```

After changing anything in `site/`, regenerate the service worker and run the checks:

```bash
python3 scripts/build_sw.py && python3 scripts/check_site.py
```

## Deploy

`.github/workflows/pages.yml` checks the bundle and deploys `site/` to GitHub Pages on every push to `main`. In the repository settings, **Pages → Build and deployment → Source** must be set to **GitHub Actions** (once).

## Install on a phone

Open the site, then use the browser's **Add to Home Screen** (iPhone Safari: Share → Add to Home Screen) or **Install app** (Android Chrome). After an update, reload; on iPhone, if the app does not update, remove and re-add the home-screen icon.
