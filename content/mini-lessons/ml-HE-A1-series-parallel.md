Resistors, lamps and appliances can be connected in two basic ways.

In a **series** circuit, the parts are connected one after another, so the **same current** passes through each. The total resistance is the **sum**: R = R1 + R2 + R3. If one bulb burns out, the path breaks and all the bulbs go off, like an old string of holiday lights.

In a **parallel** circuit, each part is connected directly across the source, so each gets the **full voltage**. Each draws the current it would draw alone. The total resistance is **less than the smallest single resistance**, so the source supplies more current overall. If one branch fails, the others keep working.

That is why house outlets and a car's headlights and radio are wired in parallel. When solving problems, ask first: is the current shared, or the voltage?
Memory aid: "Series shares current; Parallel shares voltage."
