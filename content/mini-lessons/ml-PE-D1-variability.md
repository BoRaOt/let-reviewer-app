Two classes can have the same mean but very different spreads, so teachers also measure **variability**.

The **range** is the highest score minus the lowest score. It is quick, but it uses only two scores, so one unusual score can change it a lot.

The **standard deviation (SD)** uses every score. It shows how far, on average, scores lie from the mean. To compute it: find the mean; subtract the mean from each score; square each deviation; average the squared deviations, which gives the **variance**; then take the square root of the variance to get the SD.

A small SD means scores cluster near the mean, so the class performed similarly. A large SD means scores are spread out, so the class is more varied and may need more differentiated teaching.
Memory aid: "Range = top minus bottom; SD = average distance from the mean (square, average, root)."
