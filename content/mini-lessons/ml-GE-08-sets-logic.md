A **set** is a well-defined collection of objects called **elements**. The **cardinal number** n(A) is how many elements it has; the **empty set** has none.

- **Union** A ∪ B: elements in A **or** B (or both).
- **Intersection** A ∩ B: elements in **both** A and B.
- **Complement** A′: elements of the universal set **not** in A.

For two sets, n(A ∪ B) = n(A) + n(B) − n(A ∩ B). If 25 learners like cooking, 18 like sewing and 10 like both, then 25 + 18 − 10 = 33 like at least one.

In **logic**, a **conditional** "if p, then q" is **false only when p is true and q is false**. "If it rains, the class is moved indoors" is not broken on a sunny day. A **biconditional** "p if and only if q" is true when p and q have the same truth value.
Memory aid: "Union = or, Intersection = and; a promise breaks only when the 'if' happens and the 'then' doesn't."
