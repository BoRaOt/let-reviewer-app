An **experiment** is a process with uncertain outcomes, like rolling a die. Its **sample space** is the set of all possible outcomes: {1, 2, 3, 4, 5, 6}. An **event** is a set of outcomes, such as "roll an even number" = {2, 4, 6}.

When outcomes are equally likely, the probability of an event is
P(E) = number of outcomes in E ÷ number of outcomes in the sample space.
So P(even) = 3/6 = 1/2.

Every probability lies **between 0 and 1** inclusive. 0 means impossible, 1 means certain. The probability that an event does not happen is 1 − P(E).

Example: a box has 4 red, 5 blue and 1 green marble. P(blue) = 5/10 = 1/2; P(not red) = 1 − 4/10 = 3/5.

Common errors are forgetting to count every outcome in the sample space and giving answers greater than 1.
Memory aid: "Favorable over total, always between 0 and 1."
