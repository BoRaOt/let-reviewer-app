Every TESDA HE qualification includes the unit "Perform computer operations." It has five elements.
1. **Plan and prepare:** decide what the task needs, choose the right hardware and software, and plan to follow OHS guidelines.
2. **Input data:** enter it with the right program, check it for accuracy, save it, and store it on suitable media.
3. **Access information:** open the right application and navigate with the desktop icons.
4. **Produce output:** process the data, print it, or transfer files between compatible systems.
5. **Maintain the system:** clean the equipment, do minor maintenance, replace consumables, keep **regular back-ups**, run **virus checks**, and maintain files.

All of this is done within **ergonomic guidelines**, with safe keyboard technique. Hardware includes personal computers, networked systems, printers, scanners, keyboards and mice.
Memory aid: "Plan, Put in, Pull up, Print out, Protect."
