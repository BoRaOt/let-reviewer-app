Ethics begins with a basic distinction. **Facts** describe what **is**: "Many students copy homework." **Values** say what **ought** to be: "Students ought not to copy homework."

David **Hume** pointed out the **is-ought problem**: from statements of fact alone, you cannot logically derive a statement of what ought to be done. Some extra value premise is always needed.

The **naturalistic fallacy** is the related error of assuming you can derive values directly from facts about the world. Examples: "Everyone in the barangay does it, so it must be right," or "It's natural, so it's good." Both slide from what is to what ought to be.

To reason well about a moral dilemma, separate the facts of the case, which can be checked, from the values in play, which must be argued for. Then make the value premise explicit and test it.
Memory aid: "Is ≠ Ought — name the missing value premise."
